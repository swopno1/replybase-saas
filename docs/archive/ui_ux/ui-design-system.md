# UI Design System Report

## Core Library
- **Framework**: Tailwind CSS.
- **UI Kit**: shadcn/ui (Radix-based).
- **Icons**: Lucide React.

## Patterns
- **Cards**: Standardized for metrics, bot summaries, and settings.
- **Tables**: `DataTable` component provides consistent filtering and pagination.
- **Forms**: React Hook Form + Zod for validation.

## Polish
- **Color Tokens**: Standardized `primary`, `muted`, `accent`, and `destructive` tokens.
- **Typography**: Optimized for SaaS utility using Geist Sans.
- **Resilience**: Integrated skeleton loaders for data-heavy views.

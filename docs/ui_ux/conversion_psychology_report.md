# Conversion Psychology Report

## Core Principles
- **Reciprocity**: Offering a 14-day free trial with full feature access.
- **Consistency**: "Choose your plan after setup momentum" reduces initial friction.
- **Loss Aversion**: Showing trial days remaining encourages adding billing details before trial end.

## Optimization Strategy
- **Trust Reinforcement**: Add testimonials or "Used by X businesses" to the login/register pages.
- **Urgency**: Highlight "Missed leads" in the dashboard for users with no connected channels.
- **Clarity**: Explicitly state "No credit card required" on the registration CTA.

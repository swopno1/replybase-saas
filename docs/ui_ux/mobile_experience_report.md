# Mobile Experience Report

## Dashboard Performance
- **Sidebar**: Correctly collapses into a hamburger menu/bottom bar on mobile.
- **Grid Layouts**: Status cards stack vertically on small screens.
- **Data Tables**: Use horizontal scrolling to maintain readability of lead data.

## Mobile Friction Points
- **Flow Editor**: Editing complex bot flows is difficult on mobile; recommend "Read-only" or "Summary" view for mobile users.
- **Chat Interface**: Reply composer needs careful height management to handle virtual keyboards without obscuring the message feed.

# Motion System Report

## Current Usage
- **Transitions**: Subtle fade-ins using `animate-in`.
- **Feedback**: Loading spinners (`Loader2`) used extensively.
- **Toasts**: `sonner` provides non-blocking feedback for actions.

## Opportunities for Motion
- **Onboarding**: Progress bar animations to build momentum.
- **Milestones**: "Confetti" or "Scale-up" effect when completing the final setup milestone.
- **Skeleton Transitions**: Smoother cross-fade from skeleton to actual content.

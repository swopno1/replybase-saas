# ReplyBase Operational Intelligence Hub

Welcome to the centralized documentation ecosystem for ReplyBase. This directory serves as the living product knowledge system, strategic planning framework, and technical intelligence center for the platform.

## 📂 Core Directory Structure

### 🏗️ [/docs/inspection](/docs/inspection) - Technical Master Audits
- [**System Architecture**](/docs/inspection/system-architecture.md): High-level architecture, message lifecycles, and feature landscapes.
- [**Code Quality & Engineering**](/docs/inspection/code-quality.md): Type safety, database integrity, testing coverage, and technical debt.
- [**Performance & Infrastructure**](/docs/inspection/performance.md): Bottleneck analysis, caching strategies, and DevOps/Production readiness.

### 🧩 Feature Guides & Automation
- [**Flow Builder**](/docs/flow-builder.md): Deep dive into the visual automation engine, node types, and conditional logic.

### 🛡️ [/docs/audit](/docs/audit) - Governance & Reliability
- [**Security Master Audit**](/docs/audit/security-master.md): Authentication, multi-tenant isolation, and risk remediation.
- [**Reliability & Conversational Quality**](/docs/audit/reliability-master.md): Channel stability, AI humanization, and failure recovery.

### 🎨 [/docs/ui_ux](/docs/ui_ux) - Product & Design
- [**UX Master Audit**](/docs/ui_ux/UX_MASTER_AUDIT.md): Design system core, onboarding psychology, and interaction standards.
- [**UX Task List**](/docs/ui_ux/ui_ux_tasks.md): Implementation-focused interaction and polish tasks.

### 📈 [/docs/roadmap](/docs/roadmap) & [/docs/strategy](/docs/strategy)
- [**Master Roadmap**](/docs/roadmap/master-roadmap.md): Phase-based evolution and current development cycle.
- [**Current Project Status**](/docs/strategy/current-project-status.md): Executive summary of the platform's stability and priorities.

### 📝 [/docs/TASKS.md](/docs/TASKS.md)
The centralized source of truth for all engineering and product tasks, following a strict 14-field format for implementation clarity.

## Feature Descriptions

### Core Features

#### Bots

- **Free**: 1 active bot
- **Starter**: 5 active bots
- **Pro**: 25 active bots
- **Business**: Unlimited bots with sub-accounts

#### Message Limits

- **Free**: 100 daily / 3,000 monthly
- **Starter**: 1,000 daily / 30,000 monthly
- **Pro**: 5,000 daily / 150,000 monthly
- **Business**: Unlimited

#### Flow Execution

- Number of times a conversation flow can be triggered per day
- Applies to all conversation types (messages, API calls, webhooks)

#### Channels

- Number of integration channels (Facebook, WhatsApp, Telegram, etc.) per bot
- Allows businesses to manage multi-channel conversations

#### AI Features

- **Free**: Basic text generation, no sentiment analysis
- **Starter**: Sentiment analysis, basic content generation
- **Pro**: Advanced NLP, custom training, content optimization
- **Business**: Premium AI models, custom ML pipelines, real-time personalization

### Support & Onboarding

#### Onboarding Support

- **Free**: Documentation only
- **Starter**: Email support + setup guide
- **Pro**: Live chat + email + video calls
- **Business**: Dedicated account manager + custom training

#### Priority Support

- **Free**: Community forums
- **Starter**: Standard support (24-48h response)
- **Pro**: Priority support (24h response)
- **Business**: Premium support (1h response) + phone support

### Integrations & APIs

#### API Access

- **Free**: No API access
- **Starter**: Limited API (rate limited to 100 req/min)
- **Pro**: Full API access (rate limited to 1,000 req/min)
- **Business**: Full API + Webhooks (custom rate limits)

#### Webhook Integration

- **Free**: Not available
- **Starter**: Not available
- **Pro**: 10 webhooks per bot
- **Business**: Unlimited webhooks + custom events

#### Custom Domains

- **Free**: Not available
- **Starter**: Not available
- **Pro**: 1 custom domain
- **Business**: Unlimited custom domains

### Enterprise Features

#### SSO/SAML

- **Business Only**: Enterprise single sign-on
- Integrates with corporate identity providers
- SAML 2.0 compliant

#### Data Residency

- **Business Only**: Data stored in region of choice
- Options: US, EU, APAC, Custom
- GDPR compliant

#### Compliance

- **Business Only**: HIPAA, SOC2 Type II, GDPR
- Regular security audits
- Dedicated compliance officer

#### Team Management

- **Free/Starter**: 1 team member (account owner)
- **Pro**: Up to 5 team members with role-based access
- **Business**: Unlimited team members + sub-accounts

## Trial & Freemium Model

### Trial Period

- **Duration**: 14 days
- **Available**: All plans (except Free)
- **Credit Card**: Required to activate
- **Auto-downgrade**: Automatically downgrades to Free plan after trial expires
- **Full Feature Access**: All plan features available during trial

### Free Plan Restrictions

- Limited to 1 bot
- 100 messages per day
- No AI features
- No API access
- Community support only

### Upgrade Process

1. User initiates trial or free signup
2. Trial period begins
3. Notifications sent at: Day 3, Day 7, Day 11, Day 13
4. At Day 14:
   - User can upgrade to paid plan (no additional charge for month)
   - Automatic downgrade to Free plan
   - User retains all bot data

## Billing & Subscriptions

### Billing Cycles

- **Monthly**: Charged on day of signup + 30 days
- **Annual**: Charged on day of signup + 365 days
- **Discount**: 15% savings on annual billing

### Payment Methods

- Credit/Debit cards (Visa, Mastercard, American Express)
- Stripe payment processing
- Webhooks for payment events

### Invoice Management

- Auto-generated invoices upon successful charge
- Email delivery to registered account
- PDF download available
- Invoice history dashboard

### Subscription Management

- Change plan at any time
- Downgrade: Pro-rata refund issued
- Upgrade: Difference charged immediately
- Cancel: Full refund until next billing date
- Pause subscription: 30-day hold

## Enforcement & Limits

### Hard Limits (Enforced)

- **Suspended accounts**: 0 daily message limit (cannot use platform)
- **Free accounts**: Exactly 1 bot maximum
- **Bot creation**: Blocked when limit reached

### Soft Limits (Warnings)

- Messages: Warnings at 80%, 95%, 100% of daily limit
- API calls: Rate limiting after quota exceeded
- Team members: Can exceed limit with approval

### Rate Limiting

- **Free**: 10 requests/second
- **Starter**: 100 requests/minute
- **Pro**: 1,000 requests/minute
- **Business**: Custom limits

### Overage Charges

- Currently: Not available
- Future: Overage pricing for Business plan available
